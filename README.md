# Кубок ИТиП

Адаптивный статический лендинг. HTML, CSS и JavaScript, без сервера приложения, регистрации и базы данных. Готовые файлы находятся в `dist/`. Для локального просмотра: `node server.mjs`, затем http://127.0.0.1:4173. Сервер также выводит адреса локальной сети: открыть адрес Ethernet/Wi-Fi на этом компьютере или устройстве в той же сети. По умолчанию слушает `0.0.0.0:4173`; для доступа только с компьютера задайте `HOST=127.0.0.1`. Порт меняется через `PORT`.

## Навыки проекта

В `.agents/skills/` подключены `kubok-itip-brand` и `kubok-itip-motion`: работа с оригиналами Figma, сохранение фирменного оформления и развитие анимаций. Они используют доступные навыки Figma и Sites. В рабочем каталоге Codex `.agents` связан с одноимённым каталогом исходников, чтобы навыки обнаруживались из текущего чата. Сайт работает самостоятельно без инструментов Codex.

## Анимации

Эффекты вынесены в `dist/motion.css` и `dist/motion.js`: последовательное появление первого экрана, параллакс баннера, бегущая строка, раскрытие секций, подсветка и наклон карточек, магнитные кнопки и индикатор прокрутки. Новые карточки после переключения дисциплины или сезона автоматически получают анимации. На сенсорных устройствах наклон отключён; по умолчанию системный режим уменьшенного движения отключает эффекты. Круглая кнопка «Анимации» в шапке позволяет явно включить или выключить их; выбор сохраняется в браузере и имеет приоритет над системной настройкой. При скрытии вкладки непрерывные CSS-анимации приостанавливаются.

## Бренд

На экранах шире 800 px шапка ограничена 1180 px, со скруглением 27% её высоты. Индикатор прокрутки заполняет SVG-контур шапки; на телефоне сохранена прежняя нижняя линия. Свечение мини-логотипа создаётся через `drop-shadow` по форме SVG, без ограничивающего блока.

Брендбук и оригинальные макеты: https://www.figma.com/design/eg6I7lfpbwJdk0UaosOwl9/?node-id=0-1

Брендовые цвета: Chartreuse `#E4FD2A`, Dark Teal `#0C4652`, чёрный и белый. `logo-combined.svg` — «03. Совмещенный логотип» из узла `23:216`, используется слева на первом экране. `logo-graphic.svg` — «02. Графический логотип» из узла `23:244`, сохранён как дополнительный вариант. `logo.svg` — текстовый логотип в шапке и подвале; `mark.svg` — «04. Мини-логотип» из узла `23:421`, справа на первом экране, без фона и подписи родительского фрейма. Все SVG получены напрямую из Figma и не изменены. `banner.png` — полный макет 1920×768, используется как фон заглушки медиа; `roster-1.png`…`roster-4.png` — макеты 1000×1000. Пропорции изображений сохранены. Происхождение файлов, идентификаторы узлов и места использования перечислены в `dist/assets/brand-assets.json`.

Гарнитуры брендбука: Druk Text Wide Cyr Medium (крупные заголовки), TT Travels Regular / Medium / DemiBold (текст и навигация). Пока используются системные подмены. Получить лицензированные файлы WOFF2, разместить в `dist/assets/fonts/` и раскомментировать правила `@font-face` в `styles.css`. Перед использованием подтвердить условия веб-лицензии у владельца шрифтов.

## Данные и архив сезонов

Оформленное меню сезонов (`dist/season-menu.js`) получает годы из списка в `seasons.json`, поддерживает клавиатуру и закрытие по Escape или клику снаружи.

Контент хранится в `dist/data/seasons.json`. `currentSeason` определяет сезон по умолчанию. Каждая запись `seasons` содержит собственные команды, матчевые данные, сетку, победителей, медиа и организаторов. Выбор года меняет все эти разделы. Прямая ссылка на архив: `/?season=2026`. Несуществующий год открывает текущий сезон. Выпадающий список показывает только добавленные сезоны.

Для 2027 года добавить новую запись в `seasons`, установить `year: "2027"`, обновить `currentSeason`. Не изменять запись 2026, чтобы сохранить архив. Фотографии и документы нового сезона хранить в `dist/assets/2027/`, а старые файлы оставлять на месте. Общие брендовые файлы могут использоваться несколькими сезонами.

Команды: `id`, `name`, `demo`, `image`, `players` (массив имён/ников). `demo: true` показывает отметку «Макет». После фотосессии заменить фото, названия и участников, установить `demo: false`.

Матчи в `disciplines[].matches`:

```json
{
  "id": "dota-final-2026",
  "date": "2026-07-10",
  "time": "18:00",
  "team1Id": "id-команды-1",
  "team2Id": "id-команды-2",
  "stage": "Финал",
  "status": "finished",
  "score1": 2,
  "score2": 1,
  "advancedTeamId": "id-команды-1"
}
```

Для будущих матчей использовать `status: "scheduled"`, счёт и прошедшую команду оставить `null`. Завершённые матчи автоматически попадут в «Результаты». Время указывается локальное, без пересчёта.

Сетка `bracket` — массив раундов `{ "name": "Полуфинал", "matches": [...] }`. Матч сетки: `team1Id`, `team2Id`, `score1`, `score2`, `winnerId`. Пустой массив показывает анонс. Сетка обновляется вручную вместе с матчами в JSON; автоматической синхронизации между двумя списками нет. Количество раундов не зафиксировано.

Победитель дисциплины: `winner: { "teamId": "id-команды", "photo": "assets/2026/winners-dota.jpg" }`. Пока оба значения `winner` равны `null`, финальный блок полностью скрыт.

Медиа: добавить в `media` записи `{ "type": "image", "src": "assets/2026/photo-01.jpg", "alt": "Описание кадра", "caption": "Финал" }` или `{ "type": "video", "src": "assets/2026/final.mp4", "poster": "assets/2026/final-preview.jpg", "caption": "Лучшие моменты", "mimeType": "video/mp4" }`. Галерея строится автоматически. Фото открываются в полном размере; видео воспроизводится встроенным плеером.

Регламент: заменить `regulationsUrl: null` ссылкой на PDF в папке текущего сезона. Кнопка станет активной. Организаторы: заполнить `name` у нужных ролей. Партнёры: записи `{ "name": "Название" }` в `partners`.

## Перед финальным согласованием

Дата первого экрана — `10.07.2026` по указанию пользователя. Анонс сетки после 10 октября сохранён из задания; перед запуском сверить обе даты. Место, реальные составы, расписание, имена организаторов и регламент пока не переданы. Пустые состояния не выдают тестовые результаты за настоящие.

После изменения JSON, фотографий или текста заново опубликовать `dist/`. Админ-панель и автоматическая публикация результатов не входят в эту версию.
