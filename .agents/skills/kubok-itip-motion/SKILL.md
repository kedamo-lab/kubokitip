# Анимации Кубка ИТиП

Работать в `dist/motion.js` и `dist/motion.css` относительно корня сайта; текущий корень — `work/kubok-itip`.

Развивать существующую последовательность появления первого экрана, движение мини-логотипа, бегущую строку и раскрытие секций при прокрутке. Не менять фирменные SVG ради эффектов. Наклон карточек и магнитные кнопки включать только для точного указателя.

Состояние движения задаёт класс `motion-active`. По умолчанию учитывать `prefers-reduced-motion`; явный выбор кнопки «Анимации» сохраняется в `localStorage` под ключом `cup-motion` и имеет приоритет над системной настройкой. Не оставлять глобальный CSS-запрет, который отменяет явное включение.

После перерисовки команд, фильтра или сезона приложение отправляет `cup:content-updated`. Подключать новые узлы без повторных обработчиков. При скрытии вкладки приостанавливать бесконечные эффекты; при выключении движения оставлять весь контент видимым.

Проверять фактическое изменение transform во времени, переключение в обе стороны, сохранение выбора после перезагрузки, появление новых карточек и отсутствие горизонтальной прокрутки на телефоне. Для движения, заданного в самой Figma, применять доступный `figma:figma-implement-motion`; для обычной анимации сайта этот навык не требуется.
