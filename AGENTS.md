# Работа с Кубком ИТиП

- Использовать установленный навык `figma:figma-design-to-code` при работе с графикой и макетами Figma. Перед `get_design_context` прочитать его инструкции, передавать `skillNames: "figma-design-to-code"`. Навык `figma:figma-use` подключать только при необходимости программного экспорта или работы с узлами; `figma:figma-implement-motion` — для переноса анимаций из Figma.
- Использовать `sites:sites` для изменения и публикации этого сайта. Сохранять идентификатор из `.openai/hosting.json` и текущую аудиторию. Если запрошена только локальная работа, не публиковать.
- Рабочий брендбук: https://www.figma.com/design/eg6I7lfpbwJdk0UaosOwl9/?node-id=0-1. SVG/PNG в `public/assets/` — прямые экспорты Figma. Их происхождение описано в `public/assets/brand-assets.json`. Не изменять SVG-пути.
- Интерфейсы — HTML/CSS/JavaScript в `public/`; сервер публикации — Vinext из Sites, D1 (`DB`) и R2 (`BUCKET`); локальный сервер — `server.mjs`. Сохранять адаптивность и анимации.
- Начальные настройки — `public/data/seasons.json`, живые данные — D1 либо игнорируемый `.local/content.json`. Публикация не должна стирать живые данные и файлы. Сохранять архив сезонов; дата 2026 пока 10.07.2026.
- `/admin` редактирует сайт. Проверять новые поля в панели и на лендинге, сохранять валидацию, историю и контроль revision. Сайт закрыт для всех, кроме владельца через Sites. Не открывать его публично без отдельной серверной проверки прав редактора.
- Интеграционные `node --test tests/cms.test.mjs` — только против отдельного встроенного Worker на `127.0.0.1:4180` с локальными D1/R2. Не запускать тестовые записи против публикации или рабочей `.local`.
- Проверять изменённые изображения и блоки на ПК и мобильном экране. Достаточно проверки синтаксиса затронутого JavaScript, HTTP-ответов и целевой проверки в браузере.
- `node server.mjs` запускает локальный просмотр на порту 4173 с доступом по IP локальной сети. Для просмотра только на этом компьютере задавать `HOST=127.0.0.1`. Если пользователь просит открыть локальный сайт, оставлять запущенный сервер доступным после ответа.

- Для брендовых изменений применять проектный навык [kubok-itip-brand](.agents/skills/kubok-itip-brand/SKILL.md); для анимаций — [kubok-itip-motion](.agents/skills/kubok-itip-motion/SKILL.md). Явный выбор кнопки «Анимации» имеет приоритет над системным уменьшением движения.
